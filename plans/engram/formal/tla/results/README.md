# TLC run logs

Raw TLC output for every configuration that was run while writing section 7 (TLC 2.18, Java 21,
4 workers, 6 GB heap, 560 s cap per run). `RESULTS.md` summarises them. Configurations whose log is
absent were not run within the time budget and are marked NOT RUN in section 7.1. State-space
dumps (`meta_*` directories, ~13 GB) are not kept.
