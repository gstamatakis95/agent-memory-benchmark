# TLC results

`RESULTS.md` summarises a real TLC run (TLC 2.18, Java 21, 4 workers, 10 GB heap, 30-minute cap) of every
configuration under `formal/tla/`, taken after the round-8 (D27) amendment of `ShardMove.tla`, `Durability.tla` and
`Derivation.tla`. `../EXPECT` states what each configuration is expected to do. Raw TLC logs are not kept; they are
regenerated by running TLC on each configuration.
