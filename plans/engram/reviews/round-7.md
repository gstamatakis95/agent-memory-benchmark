# Review round 7 (after D25): findings and disposition

Three reviews were run against the D25 plan (freeze-then-copy move, N160–N168) plus the three design gaps that
TLC exposed while `ShardMove.tla` was being rewritten for D25. This file is the condensed fold of the three
review files (`round-7-postgres.md`, `round-7-correctness.md`, `round-7-api.md`, now deleted) and the TLC gaps.
**Totals: 0 blockers, 11 majors, 25 minors, 5 nits, plus T7-1..T7-3 (one major-equivalent).**

**What was executed.** Postgres lens: both DDL files applied unmodified to scratch PG 16.15 + pgvector 0.8.6;
the catalog move state machine and every ownership edge exercised as `engram_move`/`engram_admin`;
`engram_seq_advance`, `engram_move_indexes_valid`, `engram_cleanup_namespace`; a 60 k-vector partial HNSW with
the real arm SQL under custom and generic plans; the exact-path CTE; a 300 k-row `fact_links` load through the
TEMP-table upsert with WAL measured; the `VerifyFrozen` hash; the `UNION ALL` hop before and after `VACUUM`;
`pg_stat_replication` as `catalog_admin` with a live walsender. Correctness lens: the `CommitChunk`-versus-
curation races executed on a reduced schema with the plan's statement shapes; the three specs read against the
prose. API lens: `buf lint`/`build`/`breaking` (FILE and WIRE_JSON) against the round-5 and first trees; §4
embeds diffed against `proto/`; 106 §2 interfaces parsed for the five-method rule; every headline number
recomputed; TLC logs in `formal/tla/results/` read against `EXPECT`.

**Pattern.** The freeze-then-copy core (static source, equality verify, catalog CAS) holds in every lens. All
eleven majors live in the post-commit recovery paths added around it (re-run after a target restore, rollback
versus the asynchronous standby, cleanup versus restore, the reconcile's epoch rule), and each passed the D25
spec only because the spec modelled the step atomically. D26 deletes those paths where a cheaper invariant makes
them unreachable rather than patching them.
